# 🍽️ MacroSnap

### AI-Powered Nutrition Buddy for Students

MacroSnap is an AI-powered nutrition assistant that helps students understand their meals through **text-based descriptions and food images**. It uses Google Gemini to analyze meals, provide estimated nutritional information, and let users have an interactive conversation about their food and nutrition.

The application also includes a **WhatsApp summary feature** that can send a summary of the conversation to the user's WhatsApp number.

---

## 🎯 Problem Statement

Students often have difficulty understanding the nutritional value of their everyday meals. Manually searching for calories, protein, carbohydrates, and fats for every meal can be time-consuming and inconvenient.

MacroSnap provides a simple conversational interface where users can describe their meal or upload a food image and receive an AI-generated nutritional analysis.

---

## 💡 Solution

MacroSnap combines **Generative AI, image understanding, and conversational interaction** into a simple web application.

A user can:

1. Enter their name and WhatsApp number.
2. Describe what they ate using text.
3. Upload a photo of their meal.
4. Ask follow-up questions about the meal.
5. Receive estimated calories and macronutrient information.
6. Request a summary of the conversation.
7. Send the summary to WhatsApp.

## ✨ Features

### 🤖 AI Nutrition Chat

Users can have a natural-language conversation with an AI nutrition buddy powered by Google Gemini.

Users can describe their meal using text and receive an AI-generated nutritional analysis.

Users can continue asking questions about their meal instead of receiving only a single analysis.

MacroSnap includes Twilio WhatsApp integration to send a summary of the nutrition conversation to the user's WhatsApp number.

The application is designed around a simple workflow suitable for students who want quick nutritional insights without using complicated tracking interfaces.

🔐 Environment Variables and Secrets

MacroSnap requires API credentials for Google Gemini and Twilio.

Sensitive credentials are stored using Streamlit secrets.

Create the following file locally:

.streamlit/secrets.toml

Add:

GEMINI_API_KEY = "your_gemini_api_key"

TWILIO_ACCOUNT_SID = "your_twilio_account_sid"

TWILIO_AUTH_TOKEN = "your_twilio_auth_token"

TWILIO_WHATSAPP_FROM = "whatsapp:+your_twilio_number"

TWILIO_CONTENT_SID = "your_twilio_content_sid"
⚠️ Security

Never commit real API keys, authentication tokens, or other credentials to GitHub.

The .streamlit/secrets.toml file is excluded using .gitignore.

🚀 Local Setup
1. Clone the Repository
git clone https://github.com/pallavitalawar25-cmd/Macrosnap.git

Move into the project directory:

cd Macrosnap
2. Create a Virtual Environment

For Linux / WSL:

python3 -m venv venv

Activate it:

source venv/bin/activate

For Windows:

python -m venv venv

Activate it:

venv\Scripts\activate
3. Install Dependencies
pip install -r requirements.txt
4. Configure Secrets

Create:

.streamlit/secrets.toml

Add your Gemini and Twilio credentials as described in the Environment Variables and Secrets section.

5. Run the Application

Start Streamlit:

streamlit run app.py

The application will be available locally through the URL provided by Streamlit, usually:

http://localhost:8501

📱 WhatsApp Integration

MacroSnap uses Twilio WhatsApp to share conversation summaries.

The integration uses:

Twilio Account SID
Twilio Authentication Token
Twilio WhatsApp sender
Twilio Content SID

The application prepares a clean summary of the nutrition conversation and passes it to the configured WhatsApp content template.

Trial Account Limitation

When using a Twilio trial account, WhatsApp messaging functionality may be restricted by Twilio's trial-account limitations. In such cases, the WhatsApp integration remains implemented in the application, but actual outbound delivery may require an account configuration that supports the required parameters.

🌟 Why MacroSnap?

Traditional nutrition tracking applications often require users to manually search for individual food items and enter quantities.

MacroSnap provides a more conversational approach:

Traditional Tracking
        │
        ├── Search food

        └── Track manually

             VS

MacroSnap
        │
        ├── Describe / Upload Meal
        ├── Ask AI
        ├── Get Estimated Nutrition
        └── Continue Conversation

This makes meal exploration simpler and more interactive.

⚠️ Disclaimer

MacroSnap provides AI-generated estimates for informational and educational purposes.

The nutritional information may not be exact because it can depend on factors such as:

Portion size
Ingredients
Preparation method
Food variations
Image quality

MacroSnap is not a medical or clinical nutrition application and should not replace professional medical or dietary advice.
